# **🖋️ Speed Scribe**

**Speed Scribe** is a fast, minimal, and responsive **Typing Speed Test App** built using **Next.js**, **TypeScript**, and **Tailwind CSS**. It measures your typing speed, accuracy, and displays results with a sleek UI.

## 🚀 Features

- ⌨️ Real-time typing test interface
- 📊 Speed & accuracy results
- 🧠 Visual countdown bar (WordTimeBar)
- 📱 Fully responsive and fast UI
- ♻️ Component-based architecture

## 🛠️ Tech Stack

- [Next.js](https://nextjs.org/) (App Router)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- PostCSS

## 📦 Installation

```bash
git clone https://github.com/jindalharry07/Speed-Scribe.git
cd Speed-Scribe
npm install
npm run dev
```

App will run on http://localhost:5000
